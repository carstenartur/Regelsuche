## Reproduced defects and corrections

| Area | Reproduction and impact | Correction and regression evidence |
| --- | --- | --- |
| Calculus definedness | `0/0`, `0/x`, zero times a partial function, `x^0`, and `1^(1/0)` could lose their undefined inputs. Integration also reused the unsafe simplifier. | Extract the canonicalizer's existing conservative guard into `ExpressionDefinedness`; reuse it in both simplifiers. Preserve ordinary total reductions and the derivative of `x^1`. `DifferentiatorTest`: 14 additional cases. |
| Numeric cost arithmetic | `x^2147483651` scored `-2147483648`; two powers with exponent 2,000,000,000 also overflowed their sum. | Compute power penalties from exact rationals, accumulate in `long`, and saturate at `Integer.MAX_VALUE`. `TransformationGoalTest` includes three overflow cases and ordinary power ordering. |
| Structural cost rewards | Nested factored powers and `a+b+a` produced negative costs despite the `CostModel` contract. | Bound factored cost at zero; give symmetry a positive operator budget before rewards. Existing transformation-goal preference tests remain active. Remove unused private compatibility remnants and correct the heuristic documentation. |
| Search priorities | Adding path penalties to a near-maximum cost wrapped; the special maximum-value branch made saturation cheaper. Best-first, A*, beam and structural-diversity ordering were affected. | Share bounded priority arithmetic; accumulate before narrowing, including target guidance. `GoalAwareSearchTest`: six additional cases covering boundary monotonicity and real queue/elite selection across all four strategies. |
| Equality saturation | Conditional cancellation merged `(x*y)/x` with `y`; non-equivalent rules and a pattern subclass whose `matches` returned false could still merge classes. | Require equivalence-preserving metadata, reject concrete applications with unresolved assumptions, and preserve subclass matching/apply semantics. Unmodified pattern rules keep direct e-node matching. `EqualitySaturationSoundnessTest`: four cases, including valid numeric cancellation. |
| JSON persistence | Writers shared one temporary pathname, overwrote another writer's file, and left temporary output after failed replacement. Several application stores wrote directly to their destination. | Each writer owns a unique temporary file in the destination directory; failures clean up only that file and preserve the original exception. Graph storage, transposition storage and job checkpoints reuse the helper. `AtomicJsonFileTest`: seven cases, including eight concurrent writers, intact payload reads, failure cleanup, relative paths and ordinary creation permissions. |

Before the respective production fixes, **25 focused cases failed** under Java 25:
19 calculus/cost/file cases, three priority cases and three saturation cases.
The final suite adds **35 tests** across core, e-graph and search. They also retain
positive controls, rather than merely disabling unsafe functionality.

The first container run exposed owner-only permissions from `createTempFile`.
A further regression reproduced the mismatch against ordinary file creation.
The writer now uses a unique regular file with `CREATE_NEW` semantics, preserving
the normal filesystem defaults and umask so host consumers can read container reports.

The calculus folding switch and e-graph application/extraction loops were split
into focused methods. Definedness and ordinary search priority formulas each have one shared
implementation; no parallel compatibility implementation was introduced. The four stateless structural policies live in `StructuralCostModel`, retaining
their existing identifiers; numeric and teaching policies reuse its operator and
depth traversal. Repository callers migrate directly without compatibility wrappers. Related regression cases extend
the existing calculus and objective test suites.

The extractor lifecycle, structural artifact checks and method-hotspot gate pass
with the original policies. The measured context-debt increase is 9.789 against
the existing limit of 10.0; no baseline or exception is changed.

## Scope boundaries and remaining work

- Review included exact scalar/AST normalization, calculus, rule applicability and
  e-graph merges, cost models and frontier ordering, mixed-work provenance/replay,
  persistence writes, architecture ownership and build contracts.
- The atomic writer guarantees independent temporary files and complete replacement
  payloads. It is not a transaction manager for multiple in-memory repositories;
  the existing non-atomic filesystem fallback and lack of crash-durability/fsync
  guarantees remain explicit.
- The mixed frontier retains its documented outer expansion classification and
  frozen mechanical v1 profile. This QA does not redefine those historical budgets.
- Repository-wide state serialization and evidence-bound artifact-loading replay
  remain the explicitly open work in #900. This change does not claim resumable
  proof authority from arbitrary JSON.
- The advisory-database/vulnerability-scanner tranche, benchmark history and campaign
  work reuse remain open in #514. Passing software QA is not a security certification
  or a proof of unrestricted mathematical correctness.
