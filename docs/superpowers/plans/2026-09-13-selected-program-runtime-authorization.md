# Selected combined-program internal authorization plan

> Execute inline with the planning/TDD workflow; no agents, protected studies or publication.

## Source-informed design

The existing `LearnedPatternRuleAuthorizationService` validates split/selection/final evidence,
replays its fixed counterexample gate and invokes `LearnedPatternRulePromoter` for exact proof.
The existing `LearnedRewriteProgramAuthorizationService` compiles only those authorized leaves and
replays their complete program lineage. Its v1 models describe genome-only held-out qualification;
the new combined selection must not be projected into those fields or spend a second final attempt.

Add strictly typed consumers to those existing services. A versioned temporal bundle binds the
externally expected combined final plan, full selected configuration, durable final result, native
assessment, split and repository revision. The leaf consumer reads that actual evidence and calls
the unchanged split, counterexample and exact promotion algorithms. A private constructor produces
the resulting leaf authority; callers cannot deserialize or fabricate it. Every genome gene that
can execute in the paired profile must be covered, including genes not referenced by the program.

The program consumer uses `compileAuthorized` and a separate versioned replay artifact binding the
selected search budget, canonical inputs/assumptions, native search observations and complete
interpreter lineage/work. A replay captures public runtime inputs, never reopens private heldouts.
Only matching real leaf authorities and independently reproduced complete replay can create the
opaque selected-program capability. Its executor and rules stay private; `execute` enforces the
frozen configuration and current revision/validity instant on each use.

Reuse the native paired evaluator's search/audit method for authorized engines through an additive
package method that accepts ordinary expressions and assumptions, without fabricating RevealCases.
Keep the original v1 hash algorithms and frozen artifacts unchanged.

## Claim boundary

Root confirmed that mathematical internal execution and external scientific/release claims remain
separate. The current project-novelty/proof/public gates describe open-target conjectures, and the
release matrix describes campaigns. Their subjects cannot be relabelled as combined programs.
This adapter creates internal executable authority only. It carries the actual combined native
evidence and records project/external novelty, public evidence, release and public promotion as
unevaluated; it grants none of those claims and does not activate a default runtime source.

## Verification

The fresh offline Maven run passed 118 tests in 18 suites: 110 inherited controls and eight new
runtime controls. The two behavioral REDs established that an exactly reproduced but genuinely
incomplete runtime replay could obtain authority, and that an issued program capability could be
used at a clock instant before its actual program authorization. Both now reject those calls.
The incomplete control freezes a two-step configuration before its synthetic study and then uses a
separate three-step public runtime input; it does not change the selected budget after reveal.
Other controls use real native proof/counterexample failures, foreign or omitted flat-gene authority,
fully rehashed lineage/assumptions/work/configuration changes, expiry and revision changes. A positive
control retains identical final ledger bytes and cannot spend a second final attempt.

The review receipt retains the exact Maven selector, RED/GREEN logs and hashes outside tracked source.
Independent review and complete integrated CI, including the separately reviewed store fixes, remain
the integration owner's next checks. No synthetic result is evidence of real study gains.
