# Held-out policy report interpretation

`regelsuche.search-policy-held-out/v1` is a deterministic experimental report.
It is intentionally separate from the public discovery Gallery.

A successful policy result requires unchanged correctness and at least a 20% gain
in the declared primary metric on a completely held-out mathematical family.
Otherwise the report records a limiting feature. In particular, safe fallback for
unseen rule IDs is a correct negative result, not evidence of cross-family learning.
