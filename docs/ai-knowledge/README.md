# AI Knowledge Snapshots

This directory contains committed documentation snapshots generated by the
`org.aiknowledge.extractor` Gradle plugin via the `publishAiKnowledgeIndex` task.

Run `./gradlew publishAiKnowledgeIndex` (requires the `ai-knowledge-extractor`
repository next to this one) to update the snapshot.

See [../ai-knowledge.md](../ai-knowledge.md) for full setup instructions.
