# AI Knowledge Snapshots

This directory is the target location for documentation snapshots generated by
the `org.aiknowledge.extractor` Gradle plugin via the
`publishAiKnowledgeIndex` task.

Snapshot JSON files in this directory are generated artifacts and are ignored by
Git (`docs/ai-knowledge/*.json`), so this README stays as the committed
scaffold.

Run `./gradlew publishAiKnowledgeIndex` (requires the `ai-knowledge-extractor`
repository next to this one) to update the snapshot.

See [../ai-knowledge.md](../ai-knowledge.md) for full setup instructions.
