# Guard controls for the four preparation stages

This companion to the eleven public amplification cases freezes nine new
inputs. It crosses Pythagorean simplification and difference of squares
after a hidden cancellation with the direct rational telescoping rule.
Each triplet fixes one expression and varies its nonzero premise: explicit
nonzero, undeclared, or explicitly zero. The rational triplet always declares
the second denominator nonzero. The source file supplies no target, rule
selector, qualification label or expected result to candidate formation.

Run every source through every cumulative profile and each of the three
original principals with the original inventory and limits. Retain all 108
decisions, raw returned candidates, stage and replay work, input premises
and any extra assumptions. Freeze each complete set of candidates before
post-qualification. For a returned candidate, qualify under the supplied
context only when every obligation is supported. Classify an added obligation
with no source support as conditional; a nonzero obligation contradicted by
the explicitly zero source premise is incompatible. This narrow qualifier
covers the finite declared scalar fragment. It supplies no general equation
solver. Repeat the coordinator on the same unlabelled input and require all
raw decisions to reproduce. Do not count conditional or incompatible edges
as authorized, and report any such candidate even if that defeats a safety
hypothesis. Report by principal and preparer, including zero gains.

## Results

The last stage admits one qualified result in each family's explicit-nonzero
case. Trig and polynomial unknowns retain `a != 0` as an extra condition.
Neither is authorized under its input alone. All explicit-zero cases return
no candidate. The rational matcher reports an unsupported required premise
for both the undeclared and zero cases. The three earlier profiles return
only the telescoping result with both denominator assumptions supplied.

The original implementation produced two incompatible local bridges: both
T3 and P3 carried `a = 0` from the input and introduced `a != 0` on the
cancellation edge. The regression rejects both edges and checks certificate
replay against the same explicit-zero boundary. The full report stores all
nine inputs, four profiles, three attempted principals, qualified results,
negative statuses and verifier reruns.
