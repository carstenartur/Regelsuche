# Prospective public residual-composition comparison v1

## Question and information boundary

Can a finite controller learned from disjoint source families prioritize
pairings of local square-completion effects while preserving all independently
checked two-square results under one source-only budget? The public
Brahmagupta–Fibonacci expression is a development control. Its historical
right-hand side may be used only in evaluation after the generated candidate
list and its digest have been frozen. No novelty or independent blind claim
is tested.

## Fixed plan grammar and controls

The shared preparation pipeline normalizes a four-term source, exposes exact
monomial squares, enumerates all component pairs and both reflected and
unreflected completions, and certifies each local effect using the existing
residual composer. A pending two-effect plan consists of two distinct
source-issued effects. Unordered pairs are enumerated lexicographically by
their source-derived effect IDs. A complete accepted plan must cover the
entire source disjointly, cancel the residual exactly, and pass independent
exact source/candidate polynomial equality. Reject overlapping, incomplete,
changed-source and forged-residual plans. Preserve assumptions, effect IDs,
primitive rule/application identities and observed cost.

The learned selector is chosen from the finite conjunctions of three
structural predicates: disjoint component IDs, opposite signs of single
monomial residuals, and identical unsigned residual monomials including
coefficient. The selector contains no source variable, occurrence ordinal,
coefficient constant, historical reference or target expression. Enumerate
all eight masks on TRAIN. Eliminate masks that lose any checked training
candidate. Minimize the number of admitted unsuccessful proposals; break
ties by fewer conditions then unsigned mask order. Freeze scores, training
evidence, selected mask and digest before VALIDATION or FINAL formation.

Evaluate the same six arms per source:
- frozen learned mask;
- fixed two-phase control with disjoint component IDs only;
- deterministic randomized order of disjoint pairs (Java Random 874235 plus
  canonical case ordinal);
- complete valid pair enumeration in canonical order;
- hand-written residual-complement selector using all three structural predicates;
- existing all-at-once residual composer, using the same effects and cap.

The common limits are four components, twelve local effects, two selected
effects, eight retained candidates, and 100,000 canonical work units per source
and arm. Account for preprocessing, local effects, pair traversal, selector
tests and native exact composer work (including polynomial products). If the
budget exhausts, retain only exact candidates completed before exhaustion.
Charge acquisition separately and include it in cold-start comparisons.
Record selected pairs, rejected work, result roots, positive primitive
depth, zeros, ties, non-use and losses.

## Inputs and frozen splits

TRAIN has `x^2+x^4+x^6+x^8`, `4*y^2+9*y^4+16*y^6+36*y^8`
and the noncancelling control `a^2+b^2+c^2+d^2`. VALIDATION uses
`u^2+u^6+u^10+u^14` and `r^2+s^2+t^2+v^2`. FINAL comprises the
public product `(a^2+b^2)*(c^2+d^2)`, the scaled transfer
`(4*p^2+9*q^2)*(25*r^2+49*s^2)` and the noncancelling independent
squares `j^2+k^2+l^2+m^2`. All sources are unconditional real polynomials.
For the public historical correspondence compare two symmetric bilinear-square
representations after candidate freeze using the existing canonicalizer and
an exact equality check. The equality of the unchanged source has depth zero
and cannot count as rediscovery.

Persist all arms and predictions; a negative cold-start or head-to-head
result is still a completed comparison. This experiment concerns the finite
checked residual grammar. It does not qualify arbitrary controller state,
well-founded proof search, or unrestricted rewrite programs.
