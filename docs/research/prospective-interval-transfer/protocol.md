# Prospective transfer to composite rectangle quadrature

Base revision: `c317739c9b4a161d38f3ba122ba3555dc4818855`. This experiment asks whether the seven existing learned rewrite schemata transfer to an independently motivated expression family, and whether reusing verified scalar-domain membership of identical immutable expressions within a query improves the net benefit. The family is a composite rectangle rule with a constant height over adjacent intervals. Its source is the sum written directly from the quadrature formula. It does not insert the expanded training coefficient used by the previous Horner and dot-product studies. The existing rule inventory includes left and right factoring. This is synthetic polynomial mathematics, not an external program sample.

## Fixed generator

Use 256 blocks of four tasks, with one example of each pair (m, orientation) from {2,3} × {L,R}. Within block b sort by the hexadecimal SHA-256 of the UTF-8 string `seed/order/b/m/orientation` (substitute the decimal numbers and literal letter), breaking ties by ascending m then orientation. A task's zero-based index is i, with n = 30001+i. Sort j from 0 through m by SHA-256 of `seed/names/i/j`, breaking ties by j. Map the ordered indices to the corresponding letters from p,q,r,s to give consecutive endpoints x_0 through x_m. Let the common height be w=(a+n). The left-associated sum contains exactly m products, in increasing j from 1 through m. Each is w*(x_j-x_(j-1)) for L or (x_j-x_(j-1))*w for R. Endpoints are formal variables. No zero insertions, sentinels, target patterns or unrelated terms are added. Distinct exact polynomial coefficient multisets must certify disjointness within FINAL and from the prior training, gate, 128 Horner, 1,024 mixed and 24 distributive-panel cases; compare FINAL to each prior signature without requiring prior panels to be mutually disjoint.

A task supplies only its exact source, no assumptions and a node-count bound of **4m+3**, the size of multiplying the original sum of widths by the height once, with the widths still explicit. The algebraic identity w*(x_m-x_0) also satisfies this bound. The task does not supply either output. Use the same per-task limits as #1429, including 8,192 logical units. Process all 1,024 inputs, even after the shared deadline. Keep per-arm rows, proof-path hashes and dictionary, setup receipts and both elapsed observations. Independently regenerate every source, check polynomial identities, reconcile the cumulative accounting and compare the deterministic files from both runs before interpreting outcomes.
