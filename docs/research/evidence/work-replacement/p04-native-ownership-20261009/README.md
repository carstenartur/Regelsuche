## Reproduction and preservation

`manifest.json` binds every retained raw file by SHA-256. Extract
`raw-evidence.tar.gz` into an empty directory; identical files use ordinary tar
hard links. It contains logs, XML, source bindings, scripts, review history and
all public corpus rows. Generated bytecode/build-cache binaries are omitted and
listed explicitly; text diagnostics and XML are retained.

`source-history.bundle` preserves the exact local source commits and correction
branches used by those receipts. From an existing repository containing accepted
main, run `git bundle verify source-history.bundle`, then inspect or fetch its
listed refs into separate local names. Its prerequisites are ancestors of the
accepted main; it does not change a branch by itself. The publication commit may
have a different ID because the GitHub connector creates commits independently.

The source-bound commands and their environment are in each run's binding.
Full suites use isolated build directories, nonincremental Java 25 compilation,
one worker and fresh reports. The public corpus runner is in
`scripts/p04-native-public-corpus`; its protocol preserves the frozen budgets
and adds a separately declared diagnostic budget to both execution variants.
