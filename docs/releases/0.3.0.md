# Regelsuche 0.3.0

Regelsuche 0.3.0 advances the project from the first reproducibly packaged symbolic-discovery workbench in 0.2.0 to a broader platform for semantic representations, safe rule preparation, exact equation-system reasoning, proof-gated learned-rule reuse and bounded mathematical synthesis.

The release deliberately keeps mechanism, retained evidence and scientific claims separate. New capabilities are executable and content-addressed, while unsupported domains, exhausted budgets, missing assumptions and unperformed evaluations remain visible rather than being converted into success.

## Highlights

### Semantic representation discovery

Version 0.3.0 makes alternative mathematical representations first-class search and evidence objects.

- A compositional matcher algebra supports nested bindings, local recognition theories, occurrence-preserving matches and explicit `MATCHED`, `NOT_MATCHED` and `INCONCLUSIVE` outcomes.
- Provenance-bound Knowledge Packs can contribute known mathematical structures without turning recognition into proof or silently enabling their consequences during candidate formation.
- Four explicit information regimes separate target-free search, catalog-blind post-hoc classification, catalog-visible navigation and hidden-structure rediscovery.
- Bounded target-free candidate formation retains exact rule inventories, assumptions, work ledgers, truncation reasons, lineages and post-freeze capability evidence.
- Preregistered formation, candidate-freeze and qualification artifacts prevent held-out references from entering search before the candidate set is frozen.
- Immutable run workspaces bind input, strategy, information boundary, budgets, revisions and every produced or unavailable artifact to one content-addressed Run ID.
- The Workbench API can retain, list, load and compare these immutable runs without mixing mutable UI state across experiments.

These facilities provide a reproducible substrate for representation research. They do not imply global optimality or autonomous novelty.

### Safe rule application and preparation

Rules can now become applicable through explicit, bounded and independently verified preparation rather than through unrecorded normalization.

The implemented preparation paths include:

- exact univariate polynomial quotient preparation for cancellation;
- associative/commutative scalar-factor exposure;
- exact common-monomial extraction;
- exact perfect-square exposure;
- rational common-denominator construction;
- structured partial-match analysis with retained residual obligations;
- bounded pattern-targeted local bridge search;
- direct-first multi-rule coordination with typed assumption guards;
- a content-addressed registry of native exact preparation specialists;
- one unified coordinator that keeps direct execution, native exact preparation, local search, concrete principal replay and independent verification distinct.

Every successful prepared application retains its assumptions and complete primitive lineage. Unsupported fragments and incomplete budgets fail closed. The unified coordinator is implemented and characterized, but it is not presented as a complete or universally enabled rule-preparation procedure.

### Exact equation-system representations

Scalar affine equations can now be treated as one mathematical system instead of as unrelated expression roots.

The product path supports:

```text
scalar equations
  -> exact A*x=b representation
  -> certified independent row/variable blocks
  -> exact Gauss-Jordan RREF
  -> unique solution, affine solution space, or contradiction witness
```

Variable ordering, rational coefficients, row provenance, ranks, elementary row operations and certificates remain reproducible. A separate symbolic representation distinguishes declared vector coordinates from scalar parameters and can recognize an explicitly modelled eigenproblem, derive `(A-lambda*I)*v=0` and compute a bounded exact characteristic polynomial.

Names alone never introduce a physical or quantum interpretation. Nonlinear systems, unsupported functions, symbolic denominators and exhausted budgets remain explicit non-success outcomes.

A retained matched-work experiment compares the representation/RREF path with an independently implemented direct scalar-elimination path under the same visible input and terminal obligations. Its implementation-defined work counts are bounded evidence for the frozen cases, not a general solver-performance claim.

### Proof-gated learned rules and generational reuse

The release contains a narrow path from mined patterns to executable experimental rules:

- assumption-free identities in a bounded commutative integer-polynomial fragment can receive an exact normal-form proof;
- a successful proof creates a new pattern-rule identity, applicability schema and promotion receipt;
- raw compiled genomes remain untrusted and do not inherit equivalence-preserving status;
- generation-separated rule mining freezes each shadow inventory before the next generation starts;
- accepted rules require validation, counterexample search, positive and negative holdouts, leakage checks, exact verification and executable compilation;
- cumulative evidence demonstrates reuse of earlier accepted generations by later shadow-inventory searches.

This changes only experimental shadow inventories. It does not promote learned rules into the default production inventory, and the public `PROMOTION` capability remains `NOT_EVALUATED`.

See [Generational rule mining](../generational-rule-mining.md).

### Exact polynomial-decomposition synthesis

The named Sophie-Germain bridge is no longer required as the default route for the corresponding quartic factorization family.

`PolynomialSemanticView` interprets complete AST subtrees such as `x + 1` or `sin(t)` as structural polynomial atoms. `PolynomialDecompositionSynthesisOperator` then solves exact coefficient constraints for bounded binary homogeneous quartics and constructs integer quadratic-by-quadratic factors with content-addressed certificates. Bounded univariate quartics are homogenized through an explicit structural unit.

The same procedure covers the historical Sophie-Germain case, unrelated quartic families and arbitrary supported AST substitutions. The specialized named bridge remains only as a disabled historical control.

The current domain is intentionally limited: binary homogeneous quartics, plus bounded univariate quartics with a structural unit, integer coefficients and quadratic-by-quadratic integer factors. This is not complete multivariate factorization.

See [Polynomial decomposition synthesis](../polynomial-decomposition-synthesis.md).

### Build, QA and distribution

- The repository baseline moves from Java 21 to Java 25 LTS without preview features.
- The complete ordinary product compiles, tests and packages through the Maven reactor.
- Maven produces the executable JAR plus ZIP and TAR distributions.
- PostgreSQL integration runs through Maven Failsafe and Testcontainers in the explicit full profile.
- More documentation, workflow, container, gallery, preregistration and evidence checks are owned by Java/JUnit rather than host-only scripts.
- Duplicate full CI work and obsolete-run verification were reduced while retaining one checkout-owned Gradle lifecycle and one complete Maven/Docker product contract.
- Dependency declarations are checked for Maven/Gradle parity.
- Cytoscape 3.34.1 is resolved and packaged from the same WebJar by both build paths; runtime-content and parity contracts reject stale or truncated product assets.
- The embedded OpenAPI document now participates in coordinated release metadata and must carry the same version as `release.properties`, the Maven reactor and citation metadata.
- Coverage, immutable evidence, source-archive and fail-closed policy contracts remain part of qualification.

## Retained comparative evidence

The primary target-free simplification comparison remains deliberately negative rather than being rewritten by the new optional capabilities:

- Regelsuche untargeted best-first reaches 6 of 7 pinned reference forms;
- native SymPy `simplify` reaches 7 of 7;
- the missing cubic exact-division result remains visible in the frozen default inventory.

Additional native SymPy operations are retained as separately named diagnostic configurations rather than selected post hoc as a best-of portfolio.

The first target-free representation matrices primarily establish information separation, candidate freezing, known-bridge qualification and reproducibility infrastructure. They do not establish a general policy winner. Likewise, the generational-learning and polynomial-synthesis results demonstrate bounded mechanisms and internally verified reuse, not external mathematical novelty.

See [Discovery status](../discovery-status.md) and [Comparative discovery benchmarks](../discovery-benchmarks.md).

## Compatibility notes

- Building and running the project now requires Java 25.
- `InputType.SYSTEM` uses the exact system-representation path by default; it no longer silently treats every equation as an unrelated scalar search root.
- Experimental evidence identities remain frozen for historical reproduction, but obsolete internal behavior is not preserved as a general product-compatibility promise.

```bash

  -DreleaseVersion=0.3.0 \
```

## Claim boundary

Regelsuche 0.3.0 provides a substantial, reproducible experimental platform and several new exact, bounded mathematical capabilities. It does **not** claim:

- externally novel mathematics;
- completion or success of the preregistered flagship FINAL TEST;
- complete polynomial factorization or a general nonlinear-system solver;
- universal superiority over SymPy, computer-algebra systems or direct solvers;
- formal proof where the retained evidence is symbolic equivalence, bounded exact verification or counterexample search;
- production qualification of learned rules;
- security, safety or production certification.

`EXTERNAL_NOVELTY_REVIEW` remains `BLOCKED`; formal proof of the retained production candidate, promotion and public evidence remain `NOT_EVALUATED`. Those statuses are not inferred from other successful profiles.
