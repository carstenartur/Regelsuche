# Regelsuche 0.2.0

Released on 12 August 2026.

Regelsuche 0.2.0 is the first release that packages the project as a reproducible symbolic-discovery workbench rather than only as a collection of experimental algorithms. It combines executable mathematical transformations with explicit evidence and claim boundaries.

## Highlights

### Symbolic exploration

- AST-based expression parsing and configurable rewrite search;
- breadth-first, depth-first, best-first, A* and beam-style search strategies;
- equality saturation through the e-graph module;
- hypothesis and reusable-rule mining from transformation paths;
- counterexample search, exact equivalence checks and proof-oriented integrations;
- bounded Groebner basis, completion and numerical-relation facilities.

### Reproducible discovery evidence

The release separates candidate formation, validation, counterexamples, project novelty, proof strength, held-out utility and external novelty instead of collapsing them into one success flag. Canonical JSON artifacts, content hashes, resource ledgers and manifest-last publication contracts retain positive, negative, unsupported and incomplete outcomes.

The available target-free simplification comparison deliberately retains a mixed result: under the frozen default inventory Regelsuche reaches six of seven pinned reference forms, while SymPy reaches seven of seven. The missing cubic exact-division capability remains visible rather than being hidden by changing the measured configuration.

### Workbench and extension surface

- browser-based mathematical workbench and HTTP API;
- search-graph, derivation and evidence views;
- command-line execution and report generation;
- local plugin, rule-file and knowledge-pack contracts;
- cryptographic plugin-artifact and index-verification foundations.

### Build and distribution

- Java 21 baseline;
- checkout-owned verification rather than GitHub-only test semantics;
- Maven-packaged executable JAR plus ZIP and TAR distributions;
- retained release manifest and SHA-256 checksums;
- one ordinary CI workflow and a separate release workflow;
- pinned container and independent-reproduction contracts for the declared environments.

## Claim boundary

Version 0.2.0 demonstrates a substantial, reproducible experimental platform for symbolic search and mathematical-discovery research. It does **not** claim that Regelsuche has already produced externally novel mathematics, completed the preregistered flagship FINAL TEST, established universal superiority over computer-algebra systems, or obtained independent expert confirmation of mathematical importance.

Those stronger claims remain gated by the real flagship preregistration and held-out evaluation, information-parity baselines and ablations, blinded expert review, and external novelty review.
