# Regelsuche 0.5.3

Diese Version erweitert das Java-Optimierungs-SDK und die Suche nach geprüften
Rechenplänen. Die Änderungen beziehen sich auf das Intervall seit 0.5.2.

## Geprüfte Rechenpläne

Das SDK kann einen gemeinsamen Polynomfaktor für Nenner herleiten und prüfen.
Es prüft auch gewichtete projektive Übergaben und kann bereits verifizierte
affine Beobachtungen wiederverwenden. Die Rechenpläne tragen ihre Voraussetzungen
mit, damit Verbraucher sie vor der Anwendung kontrollieren können.

## Suchgrenzen und nachvollziehbare Ergebnisse

Die Suche begrenzt Arbeit beim Erzeugen lokaler Suchzustände und zählt primitive
Schritte auch in zusammengesetzten Umschreibungen. Die Workbench kann erhaltene
Validierungsnachweise für endliche Daten anzeigen. Die Änderungen behandeln
Begrenzung und Nachvollziehbarkeit konkreter Suchläufe.

## Maven Central

Das Java-SDK verwendet ab 0.5.3 den Maven-Namespace `io.github.carstenartur`.
Das Optimierungs-SDK ist als `io.github.carstenartur:regelsuche-optimization-sdk:0.5.3`
adressierbar. Die BOM `io.github.carstenartur:regelsuche-bom:0.5.3` verwaltet die
Versionen der öffentlichen Bibliotheken. Java-Importe verwenden `de.regelsuche`.
Die Spring-Boot-Anwendung wird über die Produktdistribution ausgeliefert.
[Java-SDK-Anleitung](https://github.com/carstenartur/Regelsuche/blob/v0.5.3/docs/java-sdk-quickstart.md)
