Der erste Rekord einer dritten Primachse

Notiz als PDF lesen

Aus den Primzahlen 2 und 127 bilden wir alle Produkte 2i127j mit nichtnegativen ganzzahligen Exponenten. Zwei solcher Zahlen können auf der Zahlengeraden nahe beieinanderliegen, obwohl ihre Exponentenvektoren weit auseinanderliegen. Wie hoch muss man zählen, bis eine dritte Primzahl q diesen Rekord verbessert?

Satz 1. Für die feste Ausgangsbasis {2, 127} gibt es eine Primzahl q, bei der die erste Verbesserung genau an der Grenze q31 eintritt. Dort erreicht allein das Paar (2m, q31) den neuen Höchstwert. Der Beweis bestimmt m und beschreibt q durch ein explizites Primzahlintervall. Ihre Dezimalziffern braucht er nicht.

Satz 2. Bei einer festen Basis aus zwei Primzahlen p < r lasse man die neue Primzahl q über alle Primzahlen größer als r laufen. Beliebig hohe erste Exponenten treten genau dann auf, wenn der einfache Kettenbruch von logp r unbeschränkte Teilquotienten besitzt. In diesem Fall kommt jeder vorgeschriebene Exponent n ≥ 2 für unendlich viele neue Primzahlen vor. Für log2 127 ist die Entscheidung zwischen den beiden Fällen offen.

Wie der Rekord gemessen wird

Für eine Primzahlbasis P heißt eine positive ganze Zahl P-glatt, wenn alle ihre Primteiler in P liegen. Für verschiedene glatte Zahlen u < v sei d die Differenz ihrer Exponentenvektoren und κ(u, v) = ‖d‖2 / ln(v/u). Der Rekord KP(X) ist das Maximum über alle Paare bis einschließlich X, sobald es ein Paar gibt. Wir vergleichen die alte und die um q erweiterte Basis jeweils an derselben Grenze. Die erste Verbesserung liegt am kleinsten X mit KP∪{q}(X) > KP(X). Der neue Exponent eines Paares ist der Betrag der Differenz seiner beiden q-Exponenten. In den Konstruktionen mit X = qn hat jedes verbessernde Paar dort Exponent n.

Beispiel zum Nachrechnen. Für q = 191 gewinnt erstmals (253, 1917). Der Prüfer vergleicht alle 248.865 Paare unter den 706 glatten Zahlen bis 1917. Vorher erreichen Paare mit verschiedenen 191-Exponenten κ < 739. Das alte Paar (127, 128) liegt schon über 898. Am Endpunkt übertrifft das Gewinnerpaar 1.809 und alle übrigen bleiben unter 1.260. Die Rechnung verwendet nur ganze Zahlen und die durch Integration von 1/t folgenden Schranken 2(v−u)/(u+v) ≤ ln(v/u) ≤ (v−u)/u. Für die linke Ungleichung genügt die Konvexität von 1/t.

Beweis von Satz 1

Wir schreiben α = log2 127 und β = log2 q. Für die Exponentendifferenz (i, j, e) verwenden wir den normierten Wert ‖(i, j, e)‖2 / |i + jα + eβ|. Er unterscheidet sich von κ um den konstanten Faktor ln 2. Das Zertifikat enthält zwei positive ganze Zahlen a, b. Sie stammen aus dem Konvergenten mit Index 351 von α, wobei der ganzzahlige Anteil den Index 0 hat. Für den Beweis genügen die folgenden nachgerechneten Eigenschaften, mit ε = |bα − a|:

ggT(a, b) = ggT(b, 31) = 1,   a < 7b,   1/(2.952b) < ε < ε+ = 1/(2.950b).

Das Primzahlintervall. Setze n = 31, m = 7nb + 1, H = m/n, η = 1/b2 und wähle die kleinste Primzahl q > 2H. Nach Dusarts Proposition 6.8 enthält für y > 396.738 das Intervall (y, y(1 + 1/(25 ln2 y))] eine Primzahl. Für y = 2H und θ = β − H ergibt ln(1 + x) ≤ x also 0 < θ ≤ 1/(25 (ln 2)3 H2) < η.

Alle Paare vor dem Ziel. Bis qn gelten mit U = 7b + 2 > β die Schranken |i| ≤ I = nU, |j| ≤ J = nU/6 und |e| ≤ n, denn 6 < α < 7. Die Norm ist höchstens N = I + J + n. Sobald q auftritt, ist das alte Paar (2a, 127b) verfügbar, denn max(a, bα) ≤ H. Sein Wert übersteigt a/ε+.

Für 0 < |e| < n hat i + ja/b + em/n auf dem Nenner nb einen Zähler mit Rest ebm modulo n. Wegen ggT(bm, n) = 1 ist dieser Rest ungleich null. Der wirkliche logarithmische Abstand ist daher mindestens

D = 1/(nb) − Jε+/b − nη > 0.

Die rationale Prüfung ergibt N/D < a/ε+. Für e = 0 kürzt man die gemeinsame q-Potenz und erhält ein altes Paar mit gleichem Wert. Eine Differenz |e| = n ist erstmals bei qn möglich.

Das einzige Gewinnerpaar. Bei einer von null verschiedenen alten Differenz hat i + ja/b Betrag ≥ 1/b oder verschwindet. Im zweiten Fall ist (i, j) ein ganzzahliges Vielfaches von (−a, b) und der echte Abstand mindestens ε. Jeder alte Abstand ist also mindestens d = min(1/(2.952b), 1/b − Jε+/b). Am Endpunkt liegt 2m unter qn, ihr logarithmischer Abstand ist nθ. Das Paar hat Wert ≥ m/(nη). Jeder andere alte Partner liegt von 2m logarithmisch mindestens d entfernt. Die Prüfung ergibt d − nη > 0 und m/(nη) > N/(d − nη). Damit übertrifft das Zielpaar jeden alten Rekord und jeden anderen Partner mit |e| = n. Kleinere Exponentendifferenzen waren bereits durch ein altes Paar beschränkt. Das beweist Satz 1.

Beweis des Kettenbruchkriteriums

Seien p < r feste Primzahlen und q > r die hinzukommende Primzahl. Setze α = logp r und β = logp q. Eindeutige Primfaktorzerlegung macht α irrational. Alle Abstände und Werte werden im Folgenden zur Basis p normiert.

Unbeschränkte Teilquotienten

Fixiere n ≥ 2. Es gibt vollständig gekürzte Konvergente a/b mit b → ∞ und bε → 0 für ε = |bα − a|. Denn ε ist kleiner als der Kehrwert des nächsten Konvergentennenners, und dessen Verhältnis zu b ist entlang einer Teilfolge beliebig groß. Setze h = ⌈√(b/ε)⌉. Dann gelten h/b → ∞, hε → 0 und h2ε ≥ b.

Wähle s, ℓ zwischen 0 und n − 1 mit bs + aℓ ≡ 1 modulo n. Das ist wegen ggT(a, b) = 1 möglich. Setze m = nh + s und H = (m + ℓα)/n = h + O(1). Die kleinste Primzahl q > pH erfüllt wieder β = H + θ mit 0 < θ = O(H−2) = o(ε). Für alle hinreichend großen b liegen die alten Vergleichswerte pa und rb bereits unter q.

Bis qn sind |i|, |j| und die Norm O(H), wobei die Konstanten von der festen Basis und von n abhängen dürfen. Für 0 < |e| < n hat das Gitterelement i + ja/b + e(m + ℓa/b)/n Betrag mindestens 1/(nb). Sein Zähler modulo n ist e(bm + aℓ) ≡ e. Die Korrektur zum wirklichen Abstand ist höchstens (|j| + |e|ℓ/n)ε/b + nθ = o(1/b). Solche Paare haben Werte O(Hb). Das alte Vergleichspaar erreicht mindestens a/ε, von der Größenordnung b/ε. Wegen Hε → 0 bleibt es stärker.

Jeder alte Abstand beträgt schließlich mindestens ε. Verschwindet der Zähler des alten Gitterelements, so folgt dies aus der Teilerfremdheit. Andernfalls ist der Abstand mindestens (1 − O(Hε))/b > ε. Am Endpunkt qn hat der alte Zielpartner pmrℓ logarithmischen Abstand nθ und der Wert beträgt mindestens m/(nθ). Alle anderen alten Partner haben Abstand ≥ ε − nθ. Da θ/ε → 0 und m von der Größenordnung H ist, übertrifft das Zielpaar sie und den alten Rekord. Hieraus folgt die erste Verbesserung. Entlang der gewählten Teilfolge wächst q unbegrenzt.

Beschränkte Teilquotienten

Die klassische Charakterisierung schlecht approximierbarer Zahlen liefert ein c > 0 mit |i + jα| ≥ c/|j| für alle ganzzahligen i, j mit j ≠ 0. Für alte Endpunkte bis pT sei T ≥ 1. Wegen |i| ≤ T und |j| ≤ T/α ist der alte Rekord höchstens C T2, wobei C = max(1, √(1 + α−2)/(cα)). Für j = 0 ist der normierte Wert gleich 1.

Wähle eine ganze Zahl E ≥ 2 und setze B = ⌈Eβ⌉. Die (B + 1)(E + 1) Punkte jα + eβ modulo 1 für 0 ≤ j ≤ B, 0 ≤ e ≤ E sind wegen eindeutiger Primfaktorzerlegung verschieden. Eines der Kreisbogenstücke zwischen benachbarten Punkten ist höchstens so lang wie der Kehrwert ihrer Anzahl. Die Differenz der beiden Indizes liefert mit einem geeigneten ganzen i einen Vektor d = (i, j, e) mit

0 < δ = |i + jα + eβ| < 1/(BE),   |i| ≤ (α + 1)B + 1,   |j| ≤ B,   |e| ≤ E.

Somit gilt ‖d‖2 ≤ C0B mit C0 = α + 4. Bei E > 1/c muss e ≠ 0 sein, da sonst δ ≥ c/B wäre. Die positiven und negativen Koordinaten von d bilden die zwei glatten Endpunkte. An der größeren der beiden Zahlen pT gilt

T ≤ |i| + α|j| + β|e| ≤ 2(|i| + α|j|) + 1 ≤ C1‖d‖2,   C1 = 2√(1 + α2) + 1.

Der alte Rekord an dieser Grenze ist höchstens C C12‖d‖22. Dagegen ist δ‖d‖2 < C0/E. Ein einziges E > max(1/c, C C12C0) garantiert für jede Primzahl q > r einen Sieg bis zu dieser Grenze. Der Exponent bei der ersten Verbesserung ist höchstens T/β ≤ C1C0(E + 1). Damit folgt die Behauptung für beschränkte Teilquotienten und Satz 2 ist bewiesen.
