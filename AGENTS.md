# Arbeit an Regelsuche

- Bei Aufgaben zu Suche, Lernen, Discovery oder geprüften Rechenplänen zuerst den [Strategien-Index](docs/research/strategies.md) lesen. Die Codeverweise zeigen die Implementierung und die zugehörigen Tests. Die Versuchslinks erklären frühere Befunde und ihre Grenzen.
- Wenn ein PR eine Forschungsstrategie erprobt oder ihren Befund ändert, den Eintrag im selben PR aktualisieren. Hypothese, Umsetzungsstand, Befund und Folgerung getrennt angeben. Für einen behaupteten Nutzen Vergleichsverfahren und Beleg angeben.
- Nach Änderungen an referenziertem Code die Zeilenverweise anhand der [Pflegeanleitung](docs/documentation-conventions.md#codeverweise-im-strategien-index) aktualisieren. Für historische Befunde die Referenz auf den damals untersuchten Commit beibehalten.
