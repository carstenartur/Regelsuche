Regelsuche

Mathematik-Workbench – Ausdrücke erkunden, Regeln entdecken, Beweise vorbereiten.

Mathematik als Spiel – probier eine Demo

Klicke einen Button: Regelsuche entdeckt den Lösungsweg, zeigt den Suchgraph, spielt die Schritte als Replay ab, hebt die emergente Identität hervor und exportiert den Bericht. Kein Setup nötig.

Benchmark JSON Proof-Status-Legende Bericht-Bundle (.zip)

Ausdruck eingeben

Regel-Domänen

Hinweis: Die Domänen-Auswahl wird zusammen mit dem Profil an die Server-API übergeben. Domänen, die das aktuelle Profil nicht unterstützt, werden serverseitig ignoriert.


    


    
    

        

            
Gefundene Rechenwege

            

                
                
            

            

            
Detail-Erklärung

            
Klick auf einen Pfad oben, um den Rechenweg darzustellen.
                LaTeX-Quelltext kann z.B. in Obsidian/Notion eingefügt werden.

            

        

    


    
    

        

            
Suchgraph (Mathematik als sichtbarer Suchraum)

            

                
                
                
                
            

            
Im interaktiven Modus rendert cytoscape.js den Suchgraph als
                zoom-/pan-/klickbare Visualisierung mit Inspector-Panel.
                Fällt automatisch auf die Mermaid-Quelltext-Ansicht zurück, wenn das CDN nicht erreichbar ist.
                LaTeX im Inspector wird über MathJax gerendert.

            

            

            

        

    


    
    

        

            
Regelkandidaten

            

                
            

            
Beobachtete Regelkandidaten. Assumptions werden je nach Regel-Domäne
                eingeblendet (z.B. b ≠ 0 bei Quotienten, a > 0 bei Logarithmen).

            

        

    


    
    

        

            
Emergente Identitäten

            

                
            

            
Wiederkehrende Schritt-Sequenzen aus erfolgreichen Pfaden – Kandidaten für Makroregeln.
                „Als Regel übernehmen" speichert eine Identität in das Regelinventar.

            

        

    


    
    

        

            
Such-Dashboard

            

                
            

            

            
Häufigste Regeln

            

        

    


    
    

        

            
Benchmark

            

                
                JSON ansehen
            

            
Jede Zeile zeigt einen Benchmark-Lauf: Szenario, Strategie,
                Erfolg (gefunden), Laufzeit, besuchte Zustände, Schritte, eingesetzte Regeln und
                den höchsten erreichten Proof-Status. Hover über einen Status-Badge,
                um die Bedeutung zu sehen.

            

        

    


    
    

        

            
Schritt-für-Schritt-Replay

            

                
                
                
                
                
            

            

            
Zeigt jeden Schritt mit LaTeX-Darstellung und Regelbegründung.
                Play durchläuft die Schritte mit 1.2 s Pause.

        

    


    
    

        

            
Pfade vergleichen

            

                
                
                
            

            
Side-by-Side-Vergleich: gemeinsame Knoten/Regeln, Step-Diffs, Teaching-Scores,
                Annahmen-Anzahl, und Empfehlung welcher Pfad kürzer / didaktischer / mit weniger Annahmen ist.

            

        

    


    
    

        

            
Regelinventar

            

                
            

            
Aktivieren/deaktivieren oder taggen. Geänderte Tags werden lokal in der UI dargestellt;
                die Persistenz erfolgt serverseitig (sofern eine schreibende Inventory-API aktiviert ist).

            

        

    


    
    

        

            
Exporte

            
Exportiert alle entdeckten Transformationen plus das aktuelle Inventar.

            

                Markdown (.md)
                LaTeX (.tex)
                Mermaid (Graph)
                JSON-Bundle
                Suchgraph (JSON)
                Suchgraph (Mermaid)
                Suchgraph (GraphML)
                Bester Pfad (.md)
                Identitätsbericht (.tex)
            

        

    


    
    

        

            
Hilfe

            
Unterstützte Syntax

            
    
                
  • Arithmetik: + − * / ^
    • 
                
  • Klammern: (…)
    • 
                
  • Variablen: einbuchstabig (x, y, …) oder mehrbuchstabig (abc)
    • 
                
  • Funktionen: sin(x), cos(x), tan(x), log(x), ln(x), sqrt(x), exp(x), abs(x)
    • 
                
  • Gleichungen: 2*x + 3 = 7 mit Typ "Gleichung"
    • 
            

            
Workflow

            
    
                
  1. Im Tab Workbench Ausdruck, Profil und gewünschte Domänen wählen, dann „Suche starten".
    2. 
                
  2. Im Tab Pfade die gefundenen Rechenwege ansehen.
    3. 
                
  3. Im Tab Graph die entdeckten Transformationen als Mermaid-Graph.
    4. 
                
  4. Im Tab Regelkandidaten beobachtete Verallgemeinerungen prüfen
                    (inkl. Assumptions).
    5. 
                
  5. Im Tab Inventar wiederverwendbare Regeln aktivieren/deaktivieren/taggen.
    6. 
                
  6. Im Tab Exporte Bundles für Doku oder Proof-Bridge herunterladen.
    7.
